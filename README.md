# 9709 Mathematics Question Bank
Open the GitHub Pages site to browse P1 and S1 past-paper entries from 2015 to 2026. Question previews and mark schemes are loaded directly from the site's source-pdfs directory. Select entries, review the crops, and export a student or teacher PDF. Export includes complete questions and their subparts. Scanned papers may require manual crop coordinates.
The MIT licence covers the project code. Cambridge question papers and mark schemes remain subject to their respective rights.
